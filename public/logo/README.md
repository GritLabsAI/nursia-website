# Nursia logo — v2

The logo is the word **nursia** set in Bricolage Grotesque ExtraBold at −0.045em
tracking, in **one colour**, next to a rounded tile carrying the `n`.

**There is no full stop.** The colour that used to live in the dot now fills the
tile, and the tile is dynamic: teal on light grounds, highlighter yellow on dark,
plus four context colours.

Everything here is generated by `node scripts/build-logo.mjs` with the letterforms
converted to outlines, so nothing depends on the font being installed. The React
`<Logo>` renders from `src/components/logo-paths.ts`, written by the same script,
so the header and these files can never drift apart.

Do not re-set the word by typing it. Use these files, or `<Logo>`.

## Tile colours

Each tile carries a fixed `n` colour. Every pair is 4.5:1 or better.

| Tile | Hex | `n` | Ground | Use |
| --- | --- | --- | --- | --- |
| Teal | `#0B6B62` | paper | light | Primary. Site, app icon, ads, avatar. |
| Highlight | `#F5E85C` | ink | dark | Primary on ink and on photography. |
| Ink | `#14161A` | paper | light | Neutral. Invoices, legal, one-colour print. |
| Paper | `#FBFAF6` | ink | dark | Neutral on dark UI chrome. |
| Results | `#157F52` | paper | light | Score reports, streaks, milestone emails. |
| Night | `#1E3A5F` | paper | light | Night study sessions, reminders, late-hour ads. |
| Plum | `#5B3A6E` | paper | light | Educator, school and partner pages. |
| Bronze | `#8A5A1F` | paper | light | Seasonal campaigns and events. |

## Rules

- **No full stop.** Never add a dot or any punctuation back after the word.
- **One tile colour per surface**, chosen by context and kept the same there. Never randomised.
- **The word never follows the tile.** Ink on light, paper on dark, white on photos.
- **Match the ground.** Teal, ink and context tiles on light grounds; yellow and paper tiles on ink or photography.
- **Context colours stay in the tile** — never buttons, text, backgrounds or charts.
- Never the wrong-answer red as a tile. Teal and highlight never touch.
- **Clear space:** the height of the `n` in the word, on all four sides.
- **Minimum size:** lockup 120px / 30mm, word 90px / 22mm, mark 16px / 5mm.
- **Do not** stretch, rotate, outline, add a shadow, tighten the tracking, or put
  the ink logo on a mid-tone photograph — use `nursia-logo-photo.svg` there.

## In code

```tsx
import { Logo } from "@/components/Logo";

<Logo />                                  // primary lockup
<Logo tone="paper" tile="paper" />        // on the ink ground
<Logo variant="mark" tile="night" />      // app mark, context tile
```

Or inline `nursia-logo-dynamic.svg` and set the variables yourself:

```css
.nursia-logo { --nursia-tile: #157F52; --nursia-glyph: #FBFAF6; --nursia-word: #14161A; }
```

## Wired into the app

`src/app/icon.svg`, `apple-icon.png`, `opengraph-image.png`, `favicon.ico`,
`manifest.ts` and `src/components/logo-paths.ts` are all generated or fed from
this script. Re-run it after any change to the mark and they update together —
`brand-kit/logos/` is written at the same time.
