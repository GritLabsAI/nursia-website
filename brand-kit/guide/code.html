Tokens & code

The site runs on Tailwind v4 with the palette declared in an @theme block. That block is the source of truth; everything in tokens/ is generated to match it.

Source of truth

Where the system actually lives

FileHolds
src/app/globals.cssThe @theme palette and font stacks, the base layer, and every component class — .eyebrow, .prose-ns, .mark, .btn, .qcard, .qopt, .cell, .acc, .calc-key.
scripts/build-logo.mjsGenerates every logo cut from one definition, letterforms outlined. Also feeds the app icons, favicon and OG image.
brand-kit/tokens/The same values as tokens.css, tokens.json and tokens.scss, for anything outside the Next.js app — email, slides, a native app, a design tool.
Change a colour in globals.css and update brand-kit/tokens/ in the same commit. There is no build step that syncs them, so they drift the moment you forget.

The theme block

/* src/app/globals.css */
@import "tailwindcss";

@theme {
  --color-paper: #fbfaf6;
  --color-paper-2: #f4f2eb;
  --color-ink: #14161a;
  --color-ink-2: #3a3d44;
  --color-muted: #6e6b63;
  --color-rule: #e3dfd4;
  --color-teal: #0b6b62;
  --color-teal-dark: #084f49;
  --color-highlight: #f5e85c;
  --color-correct: #157f52;
  --color-wrong: #b23a2e;

  --font-display: var(--font-bricolage), ui-sans-serif, system-ui, sans-serif;
  --font-ui:      var(--font-bricolage), ui-sans-serif, system-ui, sans-serif;
  --font-body:    var(--font-source-serif), Georgia, "Times New Roman", serif;
  --font-mono:    var(--font-plex-mono), ui-monospace, Menlo, monospace;
}

Declaring them in @theme means every colour is also a utility: bg-paper, text-ink-2, border-rule, bg-teal. Do not write a raw hex in a component — if the value is not in the theme, it is not in the system.

Fonts, wired through next/font

// src/app/layout.tsx
import { Bricolage_Grotesque, Source_Serif_4, IBM_Plex_Mono } from "next/font/google";

const bricolage   = Bricolage_Grotesque({ subsets: ["latin"], variable: "--font-bricolage" });
const sourceSerif = Source_Serif_4({ subsets: ["latin"], variable: "--font-source-serif" });
const plexMono    = IBM_Plex_Mono({ subsets: ["latin"], weight: ["400","500","600","700"], variable: "--font-plex-mono" });

The fonts/ folder in this kit holds the same three faces as files, for slides, email, print and anything that cannot reach a CDN. All three are SIL Open Font Licence — free to embed, ship and subset, with the licences included.

The highlighter stroke

<h1>Fifty questions, <span class="mark">free</span>.</h1>

.mark {
  background-image: linear-gradient(var(--color-highlight), var(--color-highlight));
  background-repeat: no-repeat;
  background-position: 0 88%;
  background-size: 100% 0.42em;
  box-decoration-break: clone;   /* survives a line wrap */
}

Add .mark-draw to animate it in once over 620ms. Use that on the hero and nowhere else.

An answer row

<button class="qopt" data-state="correct">
  <span class="qkey">A</span>
  <span>Serum potassium</span>
</button>

State goes on data-state, never on a class, so the styling stays declarative and there is exactly one place each state is defined. Valid values: unset, picked, correct, wrong.

Outside the app

Using the tokens elsewhere

/* plain CSS */
@import url("tokens/tokens.css");

.cta {
  background: var(--ns-teal);
  color: #fff;
  border-radius: var(--ns-radius-control);
  min-height: var(--ns-tap-min);
  font-family: var(--ns-font-ui);
}
// Sass
@use "tokens/tokens" as ns;

.cta {
  background: ns.$ns-teal;
  border-radius: ns.$ns-radius-control;
  @include ns.ns-eyebrow;
}
// JS / design tooling
import tokens from "./tokens/tokens.json" with { type: "json" };

tokens.color.action.teal.value;   // "#0B6B62"
tokens.type.eyebrow;              // the full eyebrow recipe
tokens.rules;                     // the nine hard rules, as strings

Checklist before shipping a surface

  • Ground is paper, not white. White appears only inside a card.
  • Exactly one primary action. Exactly one highlighter stroke, or none.
  • Every border is 1px rule. Nothing casts a shadow except a card.
  • Headline in the display face, sentences in the serif, labels in mono. No exceptions.
  • Every tappable thing clears 44px.
  • Focus ring present, teal, 2px, not overridden.
  • Colour is never the only signal for a state.
  • No pass rate, no invented count, no fabricated quote, no NCSBN implication.
  • Read it out loud. If it sounds like a growth team wrote it, rewrite it.
