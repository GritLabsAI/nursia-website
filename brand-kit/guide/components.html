Pharmacological therapies · Item #4127

A client is prescribed furosemide. Which laboratory value should the nurse review before administering the first dose?

ASerum potassium
BSerum calcium
CPlatelet count
DProthrombin time

Rationale

Furosemide is a loop diuretic and wastes potassium, so hypokalaemia is the risk that changes what you do next. Calcium is affected but is not the value that would hold the dose; coagulation studies are unrelated.
